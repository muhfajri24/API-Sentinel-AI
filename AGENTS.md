## Workflow contract
- Work on exactly one task ID from `docs/CODEX_TASKS.md` per instruction. No unsolicited refactors or scope creep.
- Ask the project owner before changing business scope, using paid services, pushing to a remote, public deployment, or modifying credentials.
- All code and comments in English; progress report in concise Bahasa Indonesia.
- Python 3.11+, use type hints, Pydantic models, small modules, tests and explicit error states.
- Prioritize **Meta model integration + verifiable test execution** over visual polish.
- Do not pretend fixture output was generated by Muse Spark.
- Keep all passwords, keys, prompts containing secrets and sensitive payloads out of git/logs.
- Only execute HTTP tests against owner-authorized, allowlisted local sandbox endpoints; deny redirects and arbitrary hosts.

## Test/acceptance loop
1. Read related files, report intended tiny diff.
2. Implement task + necessary tests.
3. Run `python -m pytest -q` (or explicitly explain why unavailable).
4. Report changed files, exact test results, unverified behaviors, and next task.
